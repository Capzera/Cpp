循环结构
	自增减运算符
	+= -= *= /= %= &= |= ^= <<= >>=
	a += 1 --->> a++(后置++，先使用，后++), ++a(前置++，先++，后使用)
	a -= 1 --->> a--, --a
	for循环机制
		1. 进入初值表达式
		2. 判断条件表达式
			2.1 成立则进入循环体内，按照顺序结构依次执行代码块
			2.2	不成立，直接程序指针走到for右括号
		3. 当程序指针指向for循环的右括号时，进入增量表达式
		4. 增量表达式执行完后重复到步骤2
		for循环内的三段式，均可以省略
		continue 直接进入到增量表达式(下一层循环)
		cout << fixed << setprecision(x) << xxx;
		对浮点数xxx变量保留x位小数
	while循环机制
		while (条件表达式) {
			// 循环体1
			// 循环体2
			// 循环体3
			...
		}
		1. 判断条件是否成立
			1.1 若条件成立，进入循环
			1.2 若条件不成立，跳过循环
		嵌套循环
		题目
	do-while 循环
		do {
		
		} while (条件);
		先执行上一次循环体，再判断条件是否成立
		
	总结：
		如果初始条件不满足的情况下，do-while会比while多循环一次
		除此之外 do-while 和 while 并无二异
