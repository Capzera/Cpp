1.  什么是指针
	是C++的一个非常特殊的变量类型，不是独立的数据类型
	1.1	指针的定义
		数据类型 *变量名;
	1.2 指针存什么值
		地址
	1.3 取地址符
		&
	1.4 计算机内存地址
		存储方式：十六进制数
		栈区：操作系统自动分配的空间
		堆区：由程序员手动向操作系统索要的空间
		全局区，Data区
	1.5 指针占用内存空间
		8B
	1.6 解引用符号
		*
	1.7 什么是解引用
		获取指针指向的地址的值
2. new 和 delete 语句
	2.1 new 语句，新建内存空间
	2.2 野空间
		没有被引用/指向的内存空间
	2.3 使用delete清除自定义空间
	2.4 野指针
		指向一个无效的内存地址的指针
	2.5 空指针
		一种特殊的指针，指向的内存是0号地址，值为NULL, 空指针不能被解引用
	2.6 空指针的逻辑判断
		p == NULL p == nullptr  !p p == 0
3. 指针与数组
	3.1 指向数组的指针
		int *p = a; int *p = &a[0];
	3.2 数组指针的偏移
		p++ 指针指向对应数据类型字节向前推移
		p-- 向后推移
	3.3 指针的差
		指针与指针之间只能用减法
		表示中间差了多少个变量(而不是字节)
4.常量指针与指针常量
	4.1 常量指针
		常量指针的本质是一个指针，指向的是一个常量。
		const 变量类型 *变量名    变量类型 const *变量名
		指针本身的值可以改变，指针可以指向其他的区域
		不能通过解引用常量指针的方式修改指针所指向的值
	4.2 指针常量
		指针常量的本质是一个常量，指针本身无法指向其他区域
		指针只能和初始指向的变量绑定
		变量类型 *const 变量名
	4.3 总结
		常量和指针哪个词在前，哪个不可变
		const在前则为常量指针，*在前则为指针常量
		哪个词在后，哪个是本质
5. 字符指针与字符串、字符数组
	5.1 字符指针
		char *,和其他指针用法差异不大
	5.2 字符数组
		和通常数组一样，数组名可以被隐式转换为指向数组中第一个元素的指针
		字符数组的数组名，可以作为一个字符指针
	5.3 ***字符数组为字符串形式***
		字符数组末尾加一个'\0'，该字符数组可以当字符串使用
		字符指针指向一个以'\0'结尾的字符数组，即字符串时。它可以通过字符串相似的功能去处理
	5.4 指向字符串的指针可以使用字符串函数
	5.5 常量字符串
		字符串的字面量本质是常量，是由编译器在静态存储区中分配的一块不可修改的内存区域
	5.6 常量字符指针
		常量指针指向的值可以被修改，但不能通过解引用的方式去修改
6. 指针数组和数组指针
	6.1 指针数组
		指针的数组，本质上是一个数组，存放的元素是指针。
		变量类型* 数组名[数组长度]
		int* a[100]; 这里的指针符号必须左连接
		数组名为a，有100个元素，且每个元素为int*
	6.2 数组指针
		数组的指针，本质上是一个指针，指向一个数组。
		变量类型 (*数组名)[数组长度];
		int a[] = {1, 9, 1, 9, 8, 1, 0};
		int (*p)[7] = &a; // 将数组的地址赋值给数组指针
		cout << (*p)[2] << endl; // 输出1，将指针解引用获取下标2的元素的值
		cout << *((*p) + 2) << endl; // 输出1，将数组指针解引用以获取数组的首地址，再次解引用获取值
	6.3 数组名和数组指针的区别
		数组名隐式转换的指针指向的是数组的第一个元素的内存区域。
		数组指针指向的是整个数组的内存区域的首地址 
	6.4 总结
		数组指针指向的类型是数组，数组名隐式转换为指针后指向的类型是数组存放的变量类型
		a是数组名隐式转换后指向的是首元素，类型是int*，解引用后能操作4B的区域(1个int大小)
		int (*p)[7]是数组指针，指向整个长度为7的数组，所以解引用可以操作28B的内存区域(7个int大小)
		在进行指针运算时，两者加减相同的整数时所跳过的内存大小不同
		哪个词在后面，哪个就是本质，哪个在前面，哪个就是被修饰的对象
7. 函数指针和指针函数
	7.1 函数指针
		函数的指针，本质上是一个指针，指向的是一个函数
		返回值类型 (*指针名) (参数列表...)
		函数名可以隐式转换成指向函数的指针，一定要给指针加括号
		typedef对函数指针进行重命名，起个别名，减少冗长的变量声明，用别名替代，减少代码量
	7.2 指针函数
		指针的函数，本质是一个函数，返回值是指针。返回值类型是指针的函数
		返回值类型* 函数名(参数表...)
8. 多级指针
	指向指针的指针
	变量类型** p
	int** p，该指针指向int类型指针的指针，二级指针。
	同理，int**** p 是四级指针
9. 结构体指针
	9.1 结构体指针
		结构体的指针，本质上一个指针，指向的是一个结构体变量。
		struct 结构体名 *p = &结构体变量名;
		访问结构体变量的成员变量
		(*指针名).成员变量名;
	9.2 指向运算符 ->
		指针名->成员变量名 ===== (*指针名).成员变量名
