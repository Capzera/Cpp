1.  指针(Pointer)
	1.1 什么是指针
		是C++的特殊的数据类型，不是独立数据类型
	1.2 指针存什么
		地址
	1.3 取地址符
		&
	1.4 计算机的内存地址
		表达方式：十六进制
		栈区：操作系统自动分配的空间
		堆区：由程序员手动向操作系统要求的空间
		全局区：全局变量存放在全局区
	1.5 指针占用的字节
		32位机器：4B，64位机器：8B
	1.6 解引用符号
		*
		访问指针所存地址下保存的值
		解引用符号是C++中优先级最高的符号
2. new 和 delete 语句
	2.1 new 语句，新建内存空间
		数据类型 *指针名 = new 数据类型(初始值);
	2.2 野空间
	2.3 delete 语句，清除新建空间
		delete 指针名
		将指针指向的空间交由操作系统重新分配----假删除
		特殊的编译器下，会将指针置为空指针。
	2.4 野指针
		指向的空间是不可调控/被删除的指针
	2.5 空指针
		空指针是一种特殊的指针，指向的内存是0号地址，值为NULL，空指针不能被解引用。
	2.6 空指针逻辑判断
		p == NULL p == nullptr p == 0  !p
3. 指针与数组
	3.1 指向数组的指针
		数组名可以隐式转换为首个元素的地址
	3.2 数组指针的偏移
		对指针进行整数的加减时，内存地址加/减去指针指向类型大小的整数倍
		p++, p-- 根据p的指针类型(指向元素的类型)内存大小进行判断。
	3.3 指针之间的运算
		指针与指针之间只允许作差
		做运算的指针必须是相同类型
		差了多少个变量(字节)
4. 常量指针和指针常量
	4.1 常量指针
		常量的指针，本质上是一个指针，指向的是一个常量
		const 变量类型* 指针名     变量类型 const* 指针名
		指针的指向变量更改，指针可以指向其他区域
		指针指向的变量如果是变量则变量本身可以更改
		不能通过解引用的方式更改变量
	4.2 指针常量
		指针的常量，本质上一个常量，常量的类型是一个指针
		变量类型* const 指针名
		指针只能指向一个变量，不能再指向其他内存区域
	4.3 总结
		常量和指针哪个词在前，说明哪个不能变
		哪个词在后，说明是哪个是本质
		const在*前则为常量指针，const在*后则为指针常量
5. 字符指针与字符串、字符数组
	5.1 字符指针
		指向字符的指针和其他指针没有任何区别
		char* 指针名;
	5.2 字符数组
		和通常数组一样，字符数组名可以被隐式转换为指向数组第一个元素的指针
		数组的名字可以作为一个指针
		带'\0'的是字符串，具有字符串特性，可以使用字符串函数
		不带'\0'的是字符数组，只具有数组的特性
	5.3 字符数组的字符串形式
		在字符数组的末尾添加一个元素为'\0'
	5.4 指向字符串的指针可以使用字符串函数
		指向字符串的指针本身具有字符串的特性
		输出指向字符串的指针，相当于输出字符串
	5.5 常量字符串
		字符串本身的字面量是一个常量，是由编译器在静态存储区中分配的一块不可修改的区域
	5.6 常量字符指针
		const char* 指针名
		指向的字符串本身的值可以修改，无法通过解引用的方式远程修改。
6. 指针数组和数组指针
	6.1 指针数组
		指针的数组，本质上是一个数组，元素的类型是指针
		数据类型* 数组名[数组长度]
		[]运算顺序高于* 所以默认情况下在指针数组中，
		*和数据类型自动结合，不需要加括号
		int* a[100];
	6.2 数组指针
		数组的指针，本质上是一个指针，指向的是一个数组
		变量类型 (*指针名)[数组长度]
		int a[] = {1, 9, 1, 9, 8, 1, 0};
		int (*p)[7] = &a; // 将数组的地址整体赋值给指针p
		cout << (*p)[2] << endl; // 输出1，将指针解引用获取下标2的元素的值
		cout << *((*p) + 2) << endl;// 输出1，将指针解引用获取数组的首地址，对运算后地址再次解引用获取地址的值
	6.3 数组名和数组指针的区别
		数据类型 (*指针名)[数组大小]
		数据类型 *指针 = 数组名
		数组名隐式转换的指针指向数组第一个元素的内存区域
		数组指针是整个数组内存区域的首地址
	6.4 总结
		数组指针指向的类型是数组，数组名隐式转换为指针后指向的类型是数组存放的变量类型
		a是数组名隐式转换后指向的首元素，类型是int*，解引用后能操作4B的区域(1个int大小)
		int (*p)[7] 是数组指针，指向整个长度为7的数组，所以解引用后能操作28B的区域(7个int大小)
		哪个词在后面，哪个就是本质，哪个在前面，哪个是被修饰的对象
7. 函数指针和指针函数
	7.1 函数指针
		函数的指针，本质上是一个指针，指向的是一个函数
		返回值类型 (*指针名)(参数表...) = 函数名
		函数名可以隐式转换为函数的地址
		一定要给函数指针加括号
	7.2 指针函数
		指针的函数，本质上是一个函数，函数的返回值是指针
		返回值类型* 函数名(参数表...)
8. 多级指针
	指向指针的指针
	变量类型** 指针名;
	int** p，指向  int指针类型  的指针，2级指针
	同理，int**** p，4级指针
9. 结构体指针
	9.1 结构体指针
		结构体的指针，本质上是一个指针，指向的是一个结构体变量
		struct 结构体名* 指针名 = &结构体变量;
		访问结构体的成员变量/成员函数
		(*指针名).成员变量
		(*指针名).函数
	9.2 指向运算符
		->
		访问结构体的成员变量/成员函数
		指针名->成员变量
		指针名->函数
		p->a ======== (*p).a
	9.3 指针结构体
		指针的结构体，本质上是一个结构体，结构体的成员变量类型是指针
