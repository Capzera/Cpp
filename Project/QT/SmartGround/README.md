# SmartGround - 信奥赛算法可视化沙盒

一个基于 Qt6 和 C++17 的竞赛算法教学可视化程序。算法模块先录制 AnimFrame，再由界面逐帧播放，支持单步、自动播放和撤销重放。

## 当前进度

当前菜单注册 **22 个可运行模块**，另有 **1 个仅含头文件的模块骨架**。本轮按确认分镜完成了拓扑排序、朴素 Dijkstra、Kruskal、BFS、01 背包、LIS 和 KMP Next。

- 排序：冒泡、选择、插入、快速、归并
- 数据结构：栈、队列、单调栈、前缀和、差分、堆数组与树映射
- 搜索：闭区间二分、左闭右开二分
- 图论：并查集基础、Tarjan 强连通分量、拓扑排序、朴素 Dijkstra、Kruskal、BFS
- 动态规划：01 背包、LIS（O(N²) 与 O(N log N)）
- 字符串：KMP Next 前缀函数

## 核心设计

- 算法与渲染分离：runAlgorithm 生成帧序列，renderFrame 解释帧并更新场景
- 动画锁：m_animated=false 时即时应用状态，服务于撤销重放
- 公共动画辅助：IModule 提供交换、移动、抽取、游标、缩放和值飞行效果
- 教学视觉：数组位置、指针、空洞和图节点状态表达算法步骤

## 构建

环境要求：Qt 6.x、CMake 3.16+、C++17 编译器。

    cmake -S . -B build
    cmake --build build

在 Qt Creator 中打开根目录 CMakeLists.txt 也可以配置和构建。可执行程序入口为 src/main.cpp。

## 操作流程

1. 选择算法模块并编辑输入。
2. 点击“绘制可视化效果”初始化场景，并自动在后台完成动画帧录制。
3. 使用“下一步”“上一步”、底部进度条或“自动播放”浏览步骤。

播放和撤销都会基于录制时的输入重建场景，避免输入变化或旧画面污染重放。

播放过程中可以直接双击画布上的数组格、结点或边权标签修改数值。修改是真实生效的：继续播放时后续动画会按改后的数值重新计算，下游状态一并重新推导。重新点击“绘制可视化效果”即可清除全部修改、回到原始输入。
