## 一、 排序算法 (Sorting Algorithms)
*   **[x] 冒泡排序 (Bubble Sort)**: (已实现于 BubbleSortModule)。基础数组图元的高亮、值交换、悬浮文字动画基准。
*   **[x] 选择排序 (Selection Sort)**: 演示每一轮扫描找极值的过程，记录极值游标，最后与无序区首元素交换；明确划分“已排序前缀”和“未排序后缀”。
*   **[x] 插入排序 (Insertion Sort)**: 演示抽出当前元素（留出空位），在已排序区域从后往前比较，大于抽出元素的逐个后移，最后将抽出元素填入空位。
*   **[x] 希尔排序 (Shell Sort)**: (已实现于 ShellSortModule)。不同 gap (步长) 下的子序列分组高亮。演示步长从大到小缩小至 1 的过程，不同颜色标识当前正在进行插入排序的子序列。
*   **[x] 快速排序 (Quick Sort)**: Pivot（基准值）的选择；左右双指针 (i, j) 向中间逼近的扫描过程；元素的跨界交换；递归分治的区间划分。
*   **[x] 归并排序 (Merge Sort)**: (已实现于 `MergeSortModule`，**第 32 批重构级改造**) 自顶向下的二分拆分：数组**真的在画面上裂开**（`MS_SPLIT` 把子数组平移分开，中间留出分裂缝），一路裂成 n 个只有 1 个元素的框；再自底向上合并：每完成一个区间的合并就**把格子拼接回一起**（合缝、整段染已排序色），同时演示双指针比较、写入底部 `temp[]` 辅助数组并飞回原区间。颜色语义：未排序区淡白、左侧浅蓝、右侧浅紫、单元素已就绪、整段合并完成转深绿。
*   **[x] 计数排序 (Counting Sort)**: 已实现于 `CountingSortModule`。三阶段分离呈现：统计每个值的出现次数（计数桶）→ 计数桶转前缀和 → 从后往前遍历按桶位置回填输出数组；数值以飞行轨迹落入桶位，输出数组逐格点亮。
*   **[x] 桶排序 (Bucket Sort)**: (已实现于 `BucketSortModule`) 画面上方为原数组 `a[]`，中部为 5 个并排的桶（每桶容量 4，桶头显示已装入个数），桶内竖直槽位无缝排布（相邻单元格只保留 1 条横线），下方为输出数组 `out[]`。演示 `b = v / 20` 分桶（数值飞入桶格）、桶内升序排序（桶格逐个变亮重排）、按桶序把元素沿轨迹飞回 `out[]`。
*   **[x] 基数排序 (Radix Sort)**: (已实现于 `RadixSortModule`) LSD 最低位优先。每一趟先逐个提取当前位（个 / 十 / 百位）并高亮，再分配到 10 个数字桶（桶内槽位无缝排布，章节说明「按当前位分的 10 个桶」上移不压字），最后按桶序收集回原数组，共三趟。

## 二、 线性数据结构 (Linear Data Structures)
*   **[x] 前缀和 (Prefix Sum)**: 暴力扫描演示 vs 预处理数组 $O(1)$ 减法演示（数字飞入合并特效）。
*   **[x] 差分 (Difference Array)**: $O(1)$ 区间端点修改演示，波浪式前缀和还原过程。
*   **[x] 栈模拟 (Stack)**: `stk[++top] = x`。`top` 指针移动与数组元素的对应关系。
*   **[x] 队列模拟 (Queue)**: `q[++tail] = x` 与 `head++`。队头、队尾双指针的逻辑追赶。
*   **[x] 循环队列 (Circular Queue)**: (已实现于 `CircularQueueModule`) 画面中央是一条固定长度的环形数组 `q[N]`，`head` 与 `tail` 两个指针从数组下方外置地向上指向各自的槽位（箭头尖端不进入格子）。演示 `tail = (tail + 1) % N` 走到末尾后折返回下标 0，以及 `count == N` 队满、`count == 0` 队空两种边界。归类于「基础数据结构」。
*   **[ ] 静态数组基础**: $O(N)$ 插入（后方整体右移）与删除（后方整体左移）。
*   **[ ] 单向链表 (静态数组模拟)**: `val[N]`, `ne[N]`, `head`, `idx`。演示物理内存槽位分配与逻辑链表指针重连的线条映射。
*   **[ ] 双向链表 (静态数组模拟)**: 增加 `l[N]`, `r[N]`，演示四步指针重连过程。

## 三、 堆与优先队列 (Heaps & Priority Queue)
> **视觉要求**：同屏展示一维物理数组与二叉树拓扑结构，产生严格的同步联动。

*   **[x] 基础概念映射**: 左儿子 2i，右儿子 2i+1，父节点 i/2 关联高亮。
*   **[x] 自底向上建堆 ($O(N)$)**: 倒序遍历执行 `down()`，从叶子上方开始局部有序，最终整体合法。已并入 `HeapSortModule` 的建堆阶段。
*   **[ ] 自顶向下建堆 ($O(N \log N)$)**: 逐个 `push` 并执行 `up()`。
*   **[x] 核心调整函数 (up / down)**: 节点与父节点/子节点比较、交换、游标位移循环动画。已实现 `HeapAdjustModule`，数组↔树双视图同步，交换用弧线动画。
*   **[ ] 综合操作 (Insert/Pop/Modify)**: 插入末尾、删除堆顶（与末尾交换后逻辑切除）、修改任意位置及维护映射数组 (`ph[k]`, `hp[k]`)。
*   **[x] 堆排序 (Heap Sort)**: 堆顶与堆底持续交换，数组后方逐渐形成有序区的过程。已实现 `HeapSortModule`，有序区染绿。

## 四、 基础算法与搜索 (Basics & Search)
*   **[x] 二分查找 - 闭区间**: `L <= R`，`R = mid - 1`，淘汰半区置灰下坠特效。
*   **[x] 二分查找 - 左闭右开**: `L < R`，`R = mid`，虚无边界判定。
*   **[ ] 双指针 (Two Pointers)**: 滑动窗口同向滑动、相向滑动（类似快排划分或求两数之和）。
*   **[x] 深度优先搜索 (DFS)**: 已实现于 `DfsModule`。显式栈可视化：`stk` 栈数组 + `vis` 访问标记 + `ord` 访问序三行并置，指针随栈顶移动；节点三色态（待访问 / 栈中 / 已完成），出栈回溯时完成态加深。
*   **[x] 广度优先搜索 (BFS)**: 队列维护（出队拓展）；波纹状/等高线层级渲染（同层同色）。


## 六、 树形结构与树上 DP (Tree Algorithms & Tree DP)
> **视觉要求**：树状结构的物理排布必须清晰，父子节点之间要有明显的连线。必须能够同时展示节点本身的权值与附带的状态值（如 `dp` 值、`sz` 值）。

*   **[ ] 树的深度与层级 (Tree Depth)**: 演示 DFS/BFS 遍历过程中，节点的深度值 `d[u]` 是如何由父节点 `d[fa] + 1` 传递下来的，可配合等高线颜色渲染。
*   **[x] 子树大小统计 (Subtree Size)**: (已实现于 TreeSubtreeSizeModule) 树形 DP 经典入门。演示自底向上的回溯过程，子节点的 `sz[v]` 依次汇入父节点的 `sz[u]`，并在节点旁用气泡显示累加过程。
*   **[ ] 树的重心 (Tree Centroid)**: 演示“切断”当前节点后，周围连通块（各个子树及向上的部分）大小的计算过程。通过颜色深浅对比，直观展示找到最大连通块最小值的过程。
*   **[x] 树的直径 - 两次 DFS/BFS**: (已实现于 TreeDiameterModule) 第一遍找到最远点，画面锁定该点为起点；第二遍水波纹扩散找到终点，最后用粗红线将两点间的“直径路径”高亮连通。
*   **[ ] 最近公共祖先 - 暴力向上爬 (LCA - Naive)**: 演示两个节点交替或同时向上移动指针，直到在相交节点碰撞。
*   **[ ] 最近公共祖先 - 倍增法 (LCA - Doubling)**: 结合 `fa[u][k]` 数组。演示游标以 $2^k$ 的步长进行“大跨步”跳跃，先平齐深度，再同时向上逼近的极速折半过程。

## 七、 进阶数据结构 (Advanced Data Structures)
> **视觉要求**：重点在于揭示逻辑结构与底层一维数组（或两个数组）的映射关系。

*   **[x] 单调栈 (Monotonic Stack)**: 演示“寻找左侧第一个比它小的元素”。新元素入栈前，将栈内破坏单调性的元素毫不留情地“踢出（弹出并飘散）”，保持栈内颜色梯度/高度的单调性。
*   **[x] 单调队列 (Monotonic Queue) - 滑动窗口**: (已实现于 `MonotonicQueueModule`) 画面上方为原数组 `a[]`，中部为 `q[]` 双端队列（存下标且对应数值单调递减），下方为 `max[]` 窗口最大值输出行。演示队头淘汰滑出窗口的过期下标（`MQ_EXPIRE`）、队尾踢出被新元素支配的较小值（`MQ_POP_BACK`），队头始终即当前窗口最大值。
*   **[x] 并查集 (DSU)** (已实现于 `DSUPathCompressionModule`，**第 32 批统一为单一模块**，删除原 `DSUBasicModule`): 严格对齐课堂 `dsu` 模板 —— 初始 `pa[i] = i`（每个点的父亲是自己）、`sz[i] = 1`；`find(x)` 带路径压缩，把路径上的子节点**现场改接**到根（树形被压扁）；`merge(u, v)` 先 `find` 两端、按大小合并 `if (sz[u] < sz[v]) swap(u, v);` 后 `pa[v] = u; sz[u] += sz[v];`；`pd(u, v)` 判同集合。画面为森林图 + 右侧 `pa[]` / `sz[]` 双行数组实时同步，逐次 `merge` 让「父亲在更改 / sz 在变动」可见。
*   **[x] 树状数组 (Fenwick Tree / BIT)**: 画面上方为原数组，下方为树状数组结构。详细演示 `lowbit(x)` 的跳跃轨迹；单点修改时，一条链向右上角累加更新；求前缀和时，沿左上角跳跃收集的过程。已实现 `FenwickTreeModule`：覆盖带半透明块直接标出 `t[i]` 维护的区间，`add` 与 `sum` 两个操作各自演示跳跃轨迹与累加气泡。
*   **[x] 线段树 - 建树 (Segment Tree - Build)**: 演示自顶向下递归劈开区间，再自底向上 `pushup` 合并区间和的过程。已实现 `SegmentTreeBuildModule`，严格对齐课堂模板 `build(node, l, r, a)`（`mul[node]=1` 首行、`tr[node]=a[l]%p` 叶子赋值、`push_up` 用 `% mod`），并把 `ls=node<<1` / `rs=node<<1|1` 的移位关系打在分裂瞬间。
*   **[ ] 线段树 - 单点修改与区间查询**: 演示递归定位到叶子节点后，回溯更新整条链的路径高亮；以及区间查询时，如何完美拼凑出目标区间的过程。（区间查询已由 `SegmentTreeQueryModule` 覆盖，单点修改仍待补）
*   **[x] 线段树 - 延迟标记 (Lazy Tag)**: （极重难点）演示区间修改时，标记挂在父节点（不下放，打上特殊的 `Tag` 图标）；在下一次访问该节点时，演示 `pushdown` 动作：父节点标记分裂并下坠给左右儿子，同时更新儿子权值的过程。已实现 `SegmentTreeTagModule`，覆盖 `changeMul` / `changeAdd` / `push_down` 全流程，紫 `×k` 徽章挂父节点、下坠时沿弧线飞向左右孩子。

## 八、 经典图论模板 (Standard Graph Algorithms)
> **视觉要求**：图的节点和边权需清晰可见。算法执行时，要配合右侧或下方的核心状态数组（如 `dist[N]`, `vis[N]`, `in_degree[N]`）同步更新。

*   **[x] 图的存储 - 链式前向星 (Forward Star)**: (已实现于 ForwardStarModule) 静态数组存图演示。用物理的 `head[u]`, `to[i]`, `nxt[i]` 数组，通过飞线连接出逻辑图的形状，彻底搞懂静态链表存图。
*   **[x] 拓扑排序 (Topological Sort)**: 演示入度 `in[u]` 数组减为 0 时，节点被激活并送入队列的过程；显示输出序列和有向环残留节点。
*   **[x] 最短路 - 朴素 Dijkstra**: $O(N^2)$。将图分为“已确定集合”和“未确定集合”。每次从未确定集合中寻找 `dist` 最小的点，变色加入集合，并向外发射射线更新邻居 `dist`。
*   **[x] 最短路 - 堆优化 Dijkstra**: (已实现于 DijkstraHeapModule) $O(M \log N)$。结合优先队列图元，演示把 `{dist, u}` 塞入最小堆，每次弹出堆顶去松弛周围边的过程。严格对齐课堂最新模板：**隐去 `vis` 数组**，靠 `if (d > dis[u]) continue` 做懒删除，过期条目标暗红直接丢弃；优先队列采用「数组行 + 完全二叉树」双视图。
*   **[ ] 最短路 - Bellman-Ford / SPFA**: 演示负权边的松弛过程，重点展现 SPFA 中节点反复入队（出队后如果再次被更新更小的值，重新排队）的核心逻辑。
*   **[ ] 最短路 - Floyd 多源最短路**: 3D DP 可视化。演示外层循环 $k$ 作为“中转站”时，全图节点两两尝试通过 $k$ 缩短距离的矩阵松弛动画。
*   **[x] 最小生成树 - Kruskal**: 边集排序后，按权值从小到大扫描。结合并查集模块，演示判断两端点是否在同一集合，若不在则连上边，并在并查集中合并。
*   **[x] 最小生成树 - Prim**: 已实现于 `PrimModule`。类似 Dijkstra 的蓝白点扩展法：`dis[]` 数组记录到生成树的距离，每轮选最小候选边并松弛邻点（数值飞行入格），取边入树并染色；最终若仍有未连通节点则提示 MST 不存在。

## 九、 字符串算法 (String Algorithms)
*   **[x] KMP 算法 - Next 数组预处理**: 在模式串上方和下方分别放置双指针，演示最长公共前后缀匹配失败时，指针回退跳跃的逻辑。已按课堂模板改造为 `pi[]`、1-indexed、首格 `#` 哨兵。
*   **[x] KMP 算法 - 匹配过程**: 主串不动，模式串在下方滑动。失配时，展示模式串利用 `next` 数组瞬间向右滑动多个单位而不回退主串指针的神奇特效。已实现 `KMPMatchModule`：`p[j+1]` 恒定对齐 `s[i]` 正下方，`i` 永不回退，`j` 回退时模式串整体右跳。
*   **[x] 字典树 (Trie)**: 已实现于 `TrieModule`。**第 29 批深化为三模式**：① 插入建树——字符串转为字符流在多叉树上顺藤摸瓜，已存在的分支直接复用（节点闪亮），只有新分支才建节点（节点生长动画），末尾节点打上 `end = 1` 标记；② 查询单词——先用静态树铺底，再逐字符沿路径下降，命中分支边变紫弹跳，末端 `end = 1` 绿脉冲表示命中，无分支红闪或仅走到前缀红闪表示失败；③ 字典序遍历——按字符升序做 DFS 前序遍历，命中的单词逐个落到底部输出行，顺序严格递增。模式通过模块设置项切换，并提供查询词输入框。

## 十、 高级图论与二分图 (Advanced Graph Theory & Bipartite Graphs)
> **视觉要求**：高级图论不仅是点和边的变色，更涉及图结构的“变形”（如缩点）、以及集合的划分（左部节点与右部节点）。

*   **[x] Tarjan 强连通分量 (SCC)**: (早期已实现) 演示 DFS 搜索树生成、`dfn` 递增与 `low` 值回溯更新、节点入栈/出栈、最后弹栈并将连通分量“缩点”染成同色的大节点。
*   **[x] Tarjan 割点与桥 (Articulation Points & Bridges)**: 同样基于 `dfn` 和 `low`。割点演示：当子节点 `low[v] >= dfn[u]` 时，节点 `u` 闪烁警告标识（切断后图裂开）；桥演示：当 `low[v] > dfn[u]` 时，连接边爆红并断开。已实现 `TarjanCutVertexBridgeModule`，节点下方挂 `dfn[]`/`low[]` 状态数组，割点染红脉冲、桥加粗爆红。
*   **[ ] Tarjan 双连通分量 (v-BCC / e-BCC)**: 演示边双和点双的划分。特别是点双（割点属于多个 BCC），展示割点像“关节”一样连接着不同颜色的气泡（连通块）。
*   **[x] 二分图判定 - 染色法 (Bipartite Coloring)**: 已实现于 `BipartiteModule`。**第 29 批深化**：显式绘制 BFS 队列行（`q[]` 数组 + `head`/`tail` 双指针锚定槽位），把「染色」与「同色冲突」的因果链显式化；一旦发现相邻节点颜色相同，该边立即以警示色高亮并弹出「冲突」提示，随后沿 BFS 父指针回溯**抽出那条奇环**，用轨迹描出整条环并把环上结点染红，解释冲突的本质原因是奇数长度回路，算法终止并给出判定结论。
*   **[x] 二分图匹配 - 匈牙利算法 (Hungarian Algorithm)**: （极其适合动画）左右两列节点。演示“增广路”寻找过程：连线尝试 -> 发现目标已被占 -> 递归让原配“腾位置” -> 原配找到新欢 -> 连线交替变色的推倒重来过程。已实现 `HungarianModule`：左侧蓝、右侧橙，四段过程分色，成功匹配转绿加粗。
*   **[x] 欧拉路径/回路 (Eulerian Path/Circuit)**: 已实现于 `EulerModule`。**第 29 批深化**：先统计各点度数判定是否存在欧拉通路（仅 0 或 2 个奇度点）；再用 Hierholzer 栈式算法，**栈列 `stk[]` 与答案列 `path[]` 纵向堆叠显示**（栈底→栈顶），死路结点灰化收缩表示压栈，回溯时出栈并高亮**延迟边**（紫色描边，可开关），遇到未闭合子回路时用橙色虚线箭头**拼接**，最后用轨迹一笔描出完整欧拉路径并落到底部结果行。

## 十一、 动态规划 (Dynamic Programming)
> **视觉要求**：DP 的本质是“状态转移”。动画绝不能只是一个表格里填数字，必须有箭头从“历史状态（格子）”飞向“当前状态（格子）”，并辅以悬浮的 `max/min` 算式。

*   **[x] 01 背包 DP**: 画面主体是二维网格。演示计算 `dp[i][j]` 时，不选和选入候选值从历史状态飞来，并在当前格子比较取 Max。
*   **[x] 完全背包 DP**: 展示从同一行左侧状态转移，突出物品可重复选择。已实现 `KnapsackCompleteModule`：候选值分「不选」（上一行同列，蓝色）与「再选一次」（同行左侧，橙色）两色，箭头来自同行左侧。
*   **[x] 线性 DP - 最长递增子序列 (LIS)**: 同屏对照 $O(N^2)$ 做法的双指针扫描，以及 $O(N \log N)$ 做法中 `g` 数组（贪心数组）的二分替换过程。
*   **[x] 线性 DP - 最长公共子序列 (LCS)**: (已实现于 `LCSModule`) 矩阵上方横排两个无缝字符串数组（串 `a` 与串 `b`，中间留 40px 间隙），指针 `i` 自上而下指向 `a` 串元素、指针 `j` 自下而上指向 `b` 串元素，与矩阵的行列下标一一对应。二维网格填 `dp[i][j]` 时，字符相同取左上角 +1（浅绿），不同则左方候选（粉）与上方候选（蓝）分色高亮后取大；最后从 `dp[n][m]` 沿对角线回溯，把 LCS 字符逐个填入底部回溯路径条。
*   **[ ] 区间 DP - 石子合并 (Interval DP)**: 视觉上是一排石子。演示枚举区间长度 `len` 和分割点 `k` 的过程，底层的三角矩阵/金字塔形 DP table 逐层向上填满。
*   **[ ] 树形 DP - 没有上司的舞会**: 结合前面树形结构的渲染，展示每个节点挂载 `dp[u][0]` 和 `dp[u][1]` 两个状态。自底向上回溯时，子节点的状态按公式交叉汇总到父节点。
*   **[ ] 状压 DP - 蒙德里安的梦想 / TSP**: 重点在于“状态”的二进制可视化。将数字转化为 0/1 方块排布，演示不同行之间二进制状态兼容（如没有连续的奇数个 0、位与运算为 0 等）的匹配判定。
*   **[ ] 记忆化搜索 vs 递推 DP (Memoization vs Bottom-up)**: 以数字三角形为例。画面左侧演示朴素 DFS 产生巨大的、满是重复计算的递归调用树；画面右侧演示加入 `memo` 数组后，命中缓存直接剪枝返回的清爽效果。


## 十二、 数论与基础数学 (Number Theory & Math)
> **视觉要求**：这部分侧重于“数阵”的消除与公式推演的可视化。

*   **[x] 质数筛法 - 埃氏筛 (Sieve of Eratosthenes)**: (已实现于 SieveOfEratosthenesModule) 屏幕铺满 1~N 的数字方阵。演示找到一个素数后，它的所有倍数依次被盖上“叉号”或变灰的扫荡过程。只输入 `n`，右侧按**每行 10 个元素**排成矩阵，扫描线从左往右、从上往下定位当前数字，从 `i*i` 起按步长 `i` 划除，被划格打叉下沉并伴随波纹扩散；右侧 `prime[]` 表逐个淡入。
*   **[x] 质数筛法 - 线性筛/欧拉筛 (Linear Sieve)**: (已实现于 `EulerSieveModule`) 与埃氏筛同屏对照。右侧设**独立质数库 `prime[]`** 区域与 `p` 指针，外层 `i` 递增、内层取质数 `p` 筛掉 `i*p`；筛除瞬间高亮「最小质因子 = p」，随后立刻判断 `i % p == 0` 并 `break`（`i` 所在格染红，说明「后面的 p 不用试了」）。核心教学点：**每个合数只被它的最小质因子筛掉一次**，绝不重复划除，总复杂度 O(n)。
*   **[x] 最大公约数 - 辗转相除法 (GCD)**: 已实现于 `GcdModule`。视觉呈现为 `ValueBar` 比例长条（条长 = 数值大小）：`a % b` 求余后余数条脉冲高亮，两条交换角色，历史轮次逐条变灰保留，最终 `b = 0` 时终值变绿并标出 `gcd`。
*   **[x] 快速幂 (Fast Exponentiation)**: (已实现于 FastPowModule) 演示指数 $b$ 转换为二进制。每一位如果是 1，则结果乘以当前的“底数权重”，底数权重每一轮都在自我平方变大的分离计算过程。严格对齐课堂模板 `qpow` + `qmul`：外层位分解与内层**竖式乘法**分两层面板同时呈现，`qmul` 的 `b & 1` / `b >>= 1` / `a = (a+a) mod p` 逐步展开。
*   **[x] 扩展欧几里得 (Exgcd)**: (已实现于 `ExgcdModule`) 画面是一列自上而下的递归调用栈，每层显示当前的 `(a, b)` 与已求出的 `(x, y)`。向下递归到边界 `b = 0, x = 1, y = 0` 后逐层回溯，通过公式 `x = y'`, `y = x' - ⌊a/b⌋ y'` 更新当前层的 x、y。

## 十三、 贪心算法 (Greedy Algorithms)
> **视觉要求**：贪心算法的核心在于“排序”与“局部最优选择”。演示时需要一根“扫描线”或高亮的光标，展示按规则筛选的过程。

*   **[x] 区间调度/活动安排 (Interval Scheduling)**: 已实现于 `IntervalSchedModule`。**第 29 批深化**：画面中排列着长短不一、互相重叠的 `SegmentBar` 时间轴条并带刻度轴；按右端点排序后逐条扫描，遇到与已选活动冲突的区间用**红色虚线重叠带**标出其重叠范围，直接变灰半透明淘汰，选中的加粗高亮并统计最终选中个数。开启「显示反例对照」后会自动进入**反证阶段**：改用「按开始时间最早选」的错误准则重跑一遍，错误解单独排在下一行，与贪心解上下对照，直观证明贪心准则的正确性。
*   **[x] 哈夫曼树 (Huffman Tree)**: (已实现于 `HuffmanTreeModule`) 两阶段流线动画。**阶段一 · 排序**：顶部展示初始频率数组，乱位元素先飞出数组并高亮，再像流星一样逐个飞回排序后应在的位置。**阶段二 · 建树**：维护森林，每次取权值最小的两个结点分三种情形处理 —— 两个都是原始数据则直接作叶子连到新父节点；一个已带子树则另一个结点飞过去与之相连；两个都带子树则先把一方上移对齐到同一行再连线求和。树不是预先画好的：结点与边初始透明，随合并逐个生长淡入；每层按权值升序从左到右排列，树高与树宽变化均有补间过渡。

## 十四、 哈希与基础匹配 (Hashing & Matching)
> **视觉要求**：展示暴力解法的“回溯与冗余”，对比哈希/KMP的“一往无前”。

*   **[ ] 字符串暴力匹配 (Brute-Force)**: (必须作为 KMP 的前置对比)。演示主串指针和模式串指针同时右移，一旦失配，主串指针惨烈地“回溯”到起始点后一位，模式串指针归零的 $O(N \times M)$ 过程。
*   **[x] 字符串哈希 (String Hashing)**: (已实现于 `StringHashModule`) 已严格对标课堂模板：$p_1 = 131$，$m_1 = 998244353$。画面自上而下五行：字符 `s1` / 前缀哈希 `h1` / 字符 `s2` / 前缀哈希 `h2` / 幂表 `p`。预处理阶段演示 $p[i] = p[i-1] \cdot p_1 \bmod m_1$ 与 $h[i] = (h[i-1] \cdot p_1 + s[i-1]) \bmod m_1$；随后从 $len = \min(n_1, n_2)$ 递减枚举，用 $\text{getHash}()$ 比较「串 1 前缀 vs 串 2 后缀」与「串 2 前缀 vs 串 1 后缀」两种重叠情形，首个匹配即最长公共前后缀长度。
*   **[x] 哈希表 - 拉链法与开放寻址 (Hash Tables)**:
    *   拉链法：复用“静态数组模拟单链表”，演示发生哈希冲突时，新元素作为链表头插法挂在同一个槽位下的过程。
    *   开放寻址法：**已实现于 `HashTableModule`**。槽位行显示哈希下标与占用状态，关键字行显示实际落位元素；`h(k) = k % 7`，冲突时冲突槽染警示色并线性探测下一槽，落位后关键字行脉冲点亮。

*   **性能边界**：曲线默认按可视范围等距采样 400 点，缩放时按需重采样并做点抽稀，避免拖拽卡顿。
