1. 核心属性架构 (The 14 Attributes System)
底层 C++ 中，CardStats 需包含以下 14 种核心属性进行战斗结算：

基础生存： max_hp (最大生命), current_hp (当前生命), deploy_cost (部署费用)。

物理体系： phys_atk (物理攻击力), phys_def (物理防御), phys_pen (物理穿透，固定值忽略防御)。

法术体系： magic_atk (法术攻击力), magic_def (法术防御，进入渐近减伤公式), magic_pen (法术穿透，固定值，先从法防中扣除)。减伤上限 90%。

速度与节奏： attack_speed (攻击速度，基础设为 1.0 = 1次/秒), move_speed (移动速度，针对敌人)。

暴击体系： crit_rate (暴击率), crit_dmg (暴击伤害，基础 1.5 倍)。注：暴击率溢出 100% 的部分，需按一定比例转化为暴击伤害。

其他机制： block_count (阻挡数，核心塔防机制，类似明日方舟), attack_range_type (射程类型标识符)。

2. 核心战斗结算公式规范
物理伤害计算公式 (固定减伤 + 保底)：

有效防御 = max(0, phys_def - phys_pen)

基础伤害 = phys_atk - 有效防御

保底伤害 = phys_atk * 0.05

物理穿透 = 固定值，直接从对方物理防御中扣除。

最终物理伤害 = max(基础伤害, 保底伤害)

法术伤害计算公式 (渐近减伤模型，对标英雄联盟护甲)：

有效法术防御 = max(0, magic_def - magic_pen)

法术减伤系数 = min(有效法术防御 / (有效法术防御 + 2500.0), 0.90)

最终法术伤害 = magic_atk * (1.0 - 法术减伤系数)

法术穿透 = 固定值，从对方法术防御中扣除后再进入渐近线。减伤上限 90%，穿透在超高法防时始终有收益。

暴击溢出转换逻辑：

当 crit_rate > 1.0 时，触发必定暴击。

溢出部分公式：额外暴击伤害加成 = (crit_rate - 1.0) * 0.5

最终暴击伤害倍率 = crit_dmg + 额外暴击伤害加成

3. 战场网格与地形限制 (Grid & Terrain System)
网格系统必须支持以下地形定义，并对移动或部署产生影响：

Grass (平地)：无限制，正常通行。

Highground (高台)：仅限远程干员部署，敌人不可通行。

Water (水域)：不可部署，部分飞行/特种敌人可通行但减速。

Snow (雪地)：敌方移动速度降低 20%。

Obstacle (障碍物)：阻挡视线与弹道，不可通行，不可部署。

(后续视情况扩展 6-8 种衍生状态，如毒沼、增伤格等)

4. ASCII 驱动的攻击范围映射逻辑 (ASCII Range Mapping)
为了避免复杂的坐标偏移量硬编码，我们采用可视化的 ASCII 矩阵定义射程。

规则设定：

O (大写 O)：代表干员自身的站位（原点）。

X (大写 X)：代表可攻击的有效网格。

. (小数点)：代表不在攻击范围内的空网格。

映射逻辑：
C++ 层读取这个字符串矩阵，遍历找到 O 的索引位置，然后计算所有 X 相对于 O 的相对坐标偏移量 (x_offset, y_offset)，生成一个 Vector2i 的数组。部署时，结合干员的朝向（上下左右），通过旋转这个相对坐标数组，来决定实际覆盖的 3D 棋盘格子。
