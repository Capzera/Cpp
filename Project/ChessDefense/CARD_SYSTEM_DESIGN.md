# 卡牌系统设计文档

## 卡牌基础属性

### 卡牌标识信息
- **名称**（Name）：如"士兵(常见)"、"皇后(罕见)"
- **等阶**（Rarity）：白、绿、蓝、紫、橙、红（决定边框颜色）
- **类型**（Type）：P兵、N骑士、B主教、R城堡、Q皇后、K国王
- **属性**（Attribute）：物理、狙击、法术、奥术、时间、支援、坦克

### 卡牌成长系统
- **等级**（Level）：消耗金币/钻石提升，影响数值强度
- **星级**（Star）：1-5星，通过合成重复卡牌升星

### 游戏内货币
1. **金币**：前期升级主要货币
2. **钻石**：后期升级稀缺货币
3. **勋章**：特殊货币（待定用途）

## UI 交互优化需求

### 图鉴详情页
- **完整页面**：独立全屏界面，不是浮层遮罩
- **攻击范围可视化**：
  - 中心实心白格：角色本体
  - 灰色空心格：可攻击范围
  - 根据 range_map ASCII 生成
- **属性面板**：双列布局，可滚动
- **左上角类型标记**：斜角遮罩显示 P/N/B/R/Q/K

### 碎片合成页
- **完整界面**：不在底部展开，独立全屏
- **交互区域**：图标+文字整体可点击
- **布局优化**：居中排列，视觉更高级

### 关卡配卡
- **理念**：进入关卡时配卡，而非全局出战配置
- **实现**：关卡启动前弹出配卡界面选择本局携带卡牌

### 按钮点击区域
- 修复选关界面"卡牌仓库"按钮下半部分点击无效问题

## CardStats 扩展需求

当前 `piece_type` 字段存储棋子类型（P/N/B/R/Q/K），需要增加：
- **card_attribute**：卡牌属性（物理/狙击/法术等）
- **display_name**：显示名称（如"士兵(常见)"）
- **star_level**：星级（1-5）

## SaveManager 扩展需求

需要增加：
- **卡牌星级存储**：`card_stars_`
- **货币系统**：`gold_`、`diamond_`、`medal_`
- 移除 `deployed_cards_`（改为关卡启动时配卡）
