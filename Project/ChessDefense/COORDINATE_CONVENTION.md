# 坐标系统约定（严格遵守）

## 用户习惯坐标（通信用）
用户描述关卡布局时使用 **1-based 行列式坐标**：
- **原点**：左上角 = `(1, 1)`
- **格式**：`(行, 列)` 或 `(row, col)`
- **示例**：5x6 棋盘，左上 `(1,1)`，右下 `(5,6)`

## 代码实现坐标（内部用）
代码层（C++/GDScript）使用 **0-based 数组索引**：
- **原点**：左上角 = `(0, 0)`
- **格式**：`(x, y)` 或 `Vector2i(x, y)`
- **示例**：5x6 棋盘，左上 `(0,0)`，右下 `(4,5)`

## 转换规则
用户坐标 → 代码坐标：
```
code_x = user_row - 1
code_y = user_col - 1
```

代码坐标 → 用户坐标：
```
user_row = code_x + 1
user_col = code_y + 1
```

## 实例：第二关布局
用户描述：
- King 位置：`(5, 1)`
- 出怪点：`(1, 6)` 和 `(5, 6)`
- 路径 A：`(1,6)` → `(1,3)` → `(2,3)` → `(3,3)` → `(3,4)` → `(4,4)` → `(5,4)` → `(5,3)` → `(5,2)` → `(5,1)`
- 路径 B：`(5,6)` → `(5,1)` 直线
- 高台：`(2,2)` `(3,2)` `(4,2)` `(4,3)` `(2,4)` `(2,5)` `(3,5)` `(4,5)`
- 不可放置：`(1,2)` `(2,1)` `(2,2)` `(3,1)` `(4,1)` `(2,6)` `(3,6)` `(4,6)`

代码实现（level_config_2.gd）：
```gdscript
# 不可放置 (用户 1,2 → 代码 0,1)
board.set_terrain_at(0, 1, 5)  # (1,2)
board.set_terrain_at(1, 0, 5)  # (2,1)
board.set_terrain_at(1, 1, 5)  # (2,2)
# ...以此类推
```

代码实现（wave_manager_2.gd）：
```gdscript
# 路径 A：用户 (1,6) → 代码 (0,5)
const PATH_A: Array[Vector2i] = [
	Vector2i(0, 5),  # 用户 (1,6)
	Vector2i(0, 2),  # 用户 (1,3)
	Vector2i(1, 2),  # 用户 (2,3)
	# ...
]
```

## 注意事项
1. **用户永远说 1-based**，代码内部用 0-based
2. **行列 vs XY**：用户说"行列"，代码里 `x` 对应行、`y` 对应列
3. **左上角起算**：不论用户还是代码，都是从左上角开始
4. **沟通时优先确认坐标系**：避免混淆导致布局错位
